## 1. 产品概述

个人年度消费结构可视化仪表盘——帮助用户通过导入 CSV 账单，自动解析消费数据并以折线图、环形图、热力日历三种维度直观呈现年度支出全貌，支持图表联动筛选，数据存储于浏览器本地，适合桌面端深度分析。

- 目标用户：有记账习惯、希望复盘年度消费结构的个人用户
- 核心价值：将枯燥的账单数据转化为可交互的视觉洞察，帮助用户发现消费盲点

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册 | 导入账单、浏览图表、联动筛选、管理本地数据 |

### 2.2 功能模块

1. **仪表盘页面**：CSV 导入、总览统计卡片、月度趋势折线图、分类占比环形图、每日热力日历、交易明细表、图表联动筛选

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | CSV 导入区 | 支持拖拽/点击上传 CSV，自动解析日期、分类、商户、金额四列，解析后存入 localStorage |
| 仪表盘 | 统计概览卡片区 | 展示年度总支出、月均支出、最大单笔、消费天数等关键指标 |
| 仪表盘 | 月度趋势折线图 | 按月聚合金额，折线图展示每月支出变化趋势，支持按分类筛选 |
| 仪表盘 | 分类占比环形图 | 展示各消费分类占总支出比例，点击扇区触发联动筛选 |
| 仪表盘 | 每日热力日历 | 类似 GitHub 贡献日历，每格代表一天，颜色深浅表示支出金额，悬停显示详情 |
| 仪表盘 | 交易明细表 | 展示所有交易记录，支持按分类/日期排序，联动筛选后仅显示对应数据 |
| 仪表盘 | 联动筛选状态栏 | 显示当前生效的筛选条件（如选中的分类），提供一键清除筛选按钮 |

## 3. 核心流程

用户打开页面 → 上传 CSV 文件 → 系统自动解析并存储 → 页面渲染三类图表与明细表 → 用户点击环形图某分类 → 趋势折线图仅显示该分类月度数据、明细表仅显示该分类记录 → 热力日历同步高亮该分类日期 → 用户点击清除筛选 → 所有图表恢复全量数据

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿 (#0D1B1E) + 翡翠绿 (#10B981) 作为强调色，辅以暖金色 (#F59E0B) 点缀
- 辅助色：深灰蓝 (#1E293B) 卡片底色，浅灰 (#F1F5F9) 文字
- 按钮风格：圆角矩形，微弱渐变，hover 时发光
- 字体：DM Sans 作为界面字体，Space Grotesk 作为数字/数据字体
- 布局风格：桌面端全屏仪表盘，深色主题，卡片式布局，顶部统计栏 + 中部图表区 + 底部明细表
- 图标风格：Lucide 线性图标，与深色主题搭配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 仪表盘 | CSV 导入区 | 虚线边框拖拽区，上传图标，支持格式提示文字，拖入时边框高亮动效 |
| 仪表盘 | 统计概览卡片区 | 四张等宽卡片横排，每张卡片带图标、数值、标签，数值使用 Space Grotesk 大号字体 |
| 仪表盘 | 月度趋势折线图 | 左侧图表区占 2/3 宽度，渐变填充折线，hover 显示 tooltip，筛选时其他月份变暗 |
| 仪表盘 | 分类占比环形图 | 右侧占 1/3 宽度，环形中心显示总金额，各分类色块带标签，选中扇区弹出放大 |
| 仪表盘 | 每日热力日历 | 全宽行，7 列（周一到周日），每格圆角小方块，颜色从浅绿到深绿渐变，悬停弹出金额 tooltip |
| 仪表盘 | 交易明细表 | 全宽表格，斑马纹行，表头固定，金额右对齐，分类标签带色点，支持分页 |
| 仪表盘 | 联动筛选状态栏 | 顶部横条，筛选标签带 × 关闭按钮，"清除全部"按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 图表区域在大屏下左右并排，小屏下上下堆叠
- 明细表固定表头，内容区滚动
